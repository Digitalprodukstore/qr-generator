2. Informasi yang diproses

Ketika Anda membuat QR biasa, data yang Anda masukkan—seperti URL, teks, nomor telepon, alamat email, detail Wi-Fi, kontak, lokasi, atau acara—diproses oleh JavaScript di browser untuk membentuk QR dan pratinjau. Pada alur generator publik yang diperiksa, isi QR tidak dikirim ke endpoint API milik QR Studio Pro. Hindari memasukkan kata sandi, data keuangan, data kesehatan, atau informasi sensitif lainnya.

Jika Anda menggunakan halaman login admin, server memproses kredensial login yang dikirim melalui permintaan HTTPS untuk memverifikasi akses. Jangan pernah membagikan kredensial admin kepada pihak lain.

3. Penyimpanan di perangkat

Fitur Simpan Proyek menggunakan localStorage browser dengan kunci qrstudio.projects dan menyimpan hingga delapan proyek terakhir pada browser/perangkat yang digunakan. Pengaturan simulasi iklan lama dapat tersimpan secara lokal dengan kunci qr_kiosk_ad_config. Namun, pengaturan global Admin versi terbaru—termasuk status aktif/nonaktif 18 jenis QR dan konfigurasi mode iklan/sponsor—disimpan di server melalui Upstash Redis, bukan hanya di browser. Data proyek pada localStorage tetap khusus untuk browser/perangkat yang digunakan dan tidak otomatis tersinkron ke perangkat lain.

Logo yang dipilih diproses di browser untuk pratinjau dan desain. Perlu diketahui bahwa ekstensi browser, perangkat bersama, atau akses fisik ke perangkat dapat memengaruhi kerahasiaan data yang tersimpan secara lokal.

4. Server, keamanan, dan log teknis

Situs dan endpoint admin di-host melalui Vercel. Penyedia hosting dapat memproses data teknis permintaan seperti alamat IP, waktu permintaan, informasi browser/perangkat, URL yang diminta, dan log keamanan/operasional sesuai konfigurasi serta kebijakan retensi penyedia. QR Studio Pro tidak menetapkan atau menjanjikan periode retensi log infrastruktur yang dikendalikan penyedia hosting.

Pengaturan global Admin disimpan pada Upstash Redis dengan kunci aplikasi khusus. Data konfigurasi tersebut mencakup status aktif/nonaktif 18 jenis QR, mode iklan, status Auto Ads, ID publisher/slot, serta nama, tautan, dan tagline sponsor jika diisi. Endpoint baca pengaturan menyediakan konfigurasi yang diperlukan generator publik; akses untuk mengubahnya dibatasi pada sesi Admin yang valid. Login admin menggunakan cookie sesi qr_admin_session dengan atribut HttpOnly, Secure, dan SameSite=Strict, berlaku hingga delapan jam. Identitas sesi aktif juga disimpan di Upstash Redis dengan masa berlaku maksimal delapan jam agar sesi dapat divalidasi dan dicabut di server. Sebelum kredensial diperiksa, sistem memakai alamat IP klien yang di-hash menggunakan SHA-256 sebagai kunci pembatasan percobaan login; penghitung percobaan disimpan di Upstash Redis dengan jendela 10 menit. Upstash Redis merupakan dependensi wajib untuk login Admin: jika penyimpanan sesi atau layanan pembatasan percobaan tidak tersedia, login ditolak sementara dan tidak dilewatkan tanpa perlindungan. Jangan menganggap hash sebagai anonimisasi mutlak.

Pengelola perlu menjaga rahasia environment server, membatasi akses admin, memperbarui dependensi, dan meninjau log serta pengaturan retensi pada penyedia terkait.

5. Cookies, analitik, dan iklan

Generator publik tidak memerlukan cookie untuk membuat QR. Cookie sesi admin dijelaskan pada bagian keamanan di atas. Pada kode versi ini tidak ditemukan pemasangan Google Analytics atau permintaan iklan Google AdSense yang aktif. Kotak iklan yang terlihat merupakan placeholder/simulasi dan tidak meminta atau menayangkan iklan.

Jika analitik, iklan, atau teknologi pelacakan diaktifkan di kemudian hari, kebijakan ini harus diperbarui sebelum aktivasi untuk menjelaskan penyedia, tujuan, kategori data, cookie/identifier, pilihan pengguna, dan mekanisme persetujuan yang diwajibkan.

6. Penyedia pihak ketiga

Versi aplikasi yang diperiksa memuat Google Fonts untuk font, Tailwind CSS melalui CDN untuk styling, pustaka qrcode-generator melalui cdnjs untuk pembentukan QR, serta Vercel untuk hosting dan endpoint admin. Permintaan ke penyedia eksternal tersebut dapat mengungkapkan alamat IP, informasi browser/perangkat, waktu permintaan, dan metadata koneksi kepada penyedia terkait.

Upstash Redis digunakan untuk penyimpanan pengaturan global Admin, validasi sesi Admin, dan pembatasan percobaan login. Pengelola harus memeriksa konfigurasi deployment aktual dan menautkan kebijakan privasi masing-masing penyedia sebelum rilis final. Daftar ini perlu diperbarui jika dependensi atau penyedia berubah.
